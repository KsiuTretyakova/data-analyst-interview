## Українська
 
Інтерактивна HTML-шпаргалка для підготовки до співбесіди на позицію Junior Data Analyst: **271 питання** з прикладами відповідей, пояснених простими словами.
 
### Теми
Прескрін з рекрутером · Логіка та метод Фермі · Excel / Google Sheets · SQL · BI-системи (Power BI, Tableau) · Статистика · Теорія ймовірностей і комбінаторика · A/B-тести · Продуктові метрики · Python (Pandas, NumPy) · Інші питання
 
### Можливості
- Три мови: українська, англійська, німецька (перемикач UA / EN / DE)
- Пошук по питаннях і відповідях
- Розгортання та згортання відповідей, меню з темами
- Приклади з кодом і розрахунками
- Темна тема і версія для друку
### Як користуватися
Відкрийте `data-analyst-interview.html` у будь-якому браузері. Встановлювати нічого не потрібно, інтернет теж не потрібен.
 
### Джерело
Питання взято зі статті Романа Повзика [«250+ питань для підготовки до співбесіди початківцю в аналітиці даних»](https://dou.ua/forums/topic/44769/) (DOU) і доповнено логічними задачами. Відповіді — короткі пояснення для підготовки, а не єдино правильний варіант.

## English
 
An interactive HTML cheat sheet for Junior Data Analyst interview prep: **271 questions** with sample answers explained in plain language.
 
### Topics
Recruiter pre-screen · Logic & Fermi estimation · Excel / Google Sheets · SQL · BI tools (Power BI, Tableau) · Statistics · Probability & combinatorics · A/B tests · Product metrics · Python (Pandas, NumPy) · Other questions
 
### Features
- Three languages: Ukrainian, English, German (UA / EN / DE switcher)
- Search across questions and answers
- Expand/collapse answers, topic navigation
- Examples with code and calculations
- Dark mode and print-friendly layout
### Usage
Open `data-analyst-interview.html` in any browser. Nothing to install, and it works offline.
 
### Source
Questions are based on Roman Povzyk's article [«250+ interview prep questions for junior data analysts»](https://dou.ua/forums/topic/44769/) (DOU), extended with extra logic puzzles. The answers are short explanations for practice, not the only correct ones.
